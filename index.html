壹 · 使用指南从订阅到第一次连接,中间有几步

按下面的顺序进行,大约只需要十来分钟。如果中途遇到疑问,翻到本页末尾的常见问题区,大多数情况都能找到对应说明。

01

挑选合适的一档,记下结算方式

兰溪谷目前提供基础版、旗舰版与团队版三档。差别主要在每月流量、设备上限以及是否包含专线与专属服务;若只是个人写作与浏览,基础版已经够用,需要长时间高质量线路再考虑升级。

02

在用户中心获取订阅链接

完成下单之后,登录兰溪谷用户中心即可看到一串以特定前缀开头的订阅地址。建议在安全的环境下复制,避免被无关软件误读;链接本身只对当前账号开放,请勿分享给他人。

03

在客户端粘贴订阅并刷新

在桌面或手机客户端的「订阅」一项中,把上一步得到的地址粘贴进去,等待几秒让节点列表同步。首次同步可能稍慢,后续每次点击「更新订阅」即可拉取最新节点。

04

按场景选择节点,开始使用

节点列表会按地区与类型分组。如果只是为了日常浏览,选择延迟较低的节点即可;若需要长时间观看视频或进行跨国资料传输,建议优先选择标注「IPLC」「专线」字样的节点。

叁 · 客户端在不同设备上的常见形态

兰溪谷的订阅地址是通用格式,理论上兼容多数遵循同一规范的应用。下列几类客户端在用户中较为常见,具体下载地址与版本以你所用平台的应用商店为准。

桌面端(Windows / macOS)

WINDOWS 10+ · MACOS 11+

桌面端在节点切换上更灵活,通常支持按程序分流和系统代理两种模式。如果工作里需要长时间挂着,推荐选择支持开机自启的版本,避免每次手动开启。

移动端(iOS / Android)

IOS 14+ · ANDROID 8+

移动端常以 VPN 配置或应用内代理的形式运行。首次安装时需要信任相应证书或允许 VPN 权限,完成后即可在状态栏看到连接图标,方便随时查看状态。

命令行 / 路由器

OPENWRT · CLI

熟悉命令行的用户可以将订阅地址转换成配置,用于路由器或自建脚本环境。这一类方式更适合团队版用户,把整个局域网交给代理节点统一调度。

浏览器扩展

CHROME / EDGE / FIREFOX

浏览器扩展通常作用于 HTTP 与 HTTPS 流量,适合只需要在浏览器里访问外部资料、不希望影响其他应用的情况。系统级操作仍然需要回到桌面端处理。

肆 · 常见问题按主题分组,按场景查找

如果下面没有涵盖你的疑问,可在用户中心提交工单;旗舰版与团队版的工单会被优先处理。

订阅与付款

兰溪谷是否提供免费试用?

目前不开放长期免费试用,但在部分活动期会放出短期体验码,具体以官网公告为准。请勿相信第三方渠道分享的所谓「永久激活码」。

按月付和按年付之间的差别在哪里?

按年付的总价相当于十个月的费用,平均到每个月更划算一些;按月付灵活度更高,适合先体验再决定的用户。两者在功能与节点上没有差别。

中途想升级或降级套餐,怎么处理?

在用户中心提交变更申请即可。系统会根据剩余天数折算差价,降级时多出的部分会以余额的形式留在账号里,供后续使用。

设备与节点

可以同时在多少台设备上使用?

具体数量取决于所选套餐:基础版 3 台,旗舰版 5 台,团队版 20 台。这里的「设备」指的是同时在线的连接数,而非累计登录次数。

节点列表里那些字母缩写代表什么?

常见的有按地区划分的缩写(如 JP、SG、US),以及按线路类型标注的关键词(如「IPLC」「专线」「普通」)。同一地区的不同线路在稳定性与延迟上会有差别。

为什么同一个节点在不同时间表现不同?

跨境线路的延迟与带宽受多个因素影响,包括本地运营商、当下时段与目标服务器的负载。兰溪谷会持续记录这些数据并淘汰表现不佳的节点。

使用与排查

连接上了却打不开网页,可能是什么原因?

先确认系统时间是否准确,误差过大会导致 TLS 握手失败;其次检查客户端是否设置为全局代理,部分应用默认绕过了代理设置。

流量是如何计算的?

按实际通过代理节点的字节数计量,上行与下行都计入总量。客户端本地缓存、局域网内网通信与未被代理的流量不计入套餐流量。

海外出差或回国期间使用,需要做什么?

建议在出发前先在客户端里更新一次订阅,确认节点列表为最新版本;落地后若发现部分节点不可用,切换到延迟更低的地区即可,通常不需要调整订阅链接。

账户与隐私

兰溪谷会保留访问日志吗?

出于故障排查的需要,系统会短时间保留必要的连接元数据(如时间、节点、流量),但不会保留具体的访问内容记录,相关数据在到期后会按既定规则清除。

忘记密码怎么办?

在登录页点击「找回密码」,通过注册邮箱接收一次性重置链接即可。若邮箱也无法使用,需要联系人工客服并提供必要的身份验证信息。

伍 · 写在后面给愿意读到这里的人

兰溪谷并不是一个用来炫耀参数的项目。它更像一本愿意被反复翻阅的小册子,把每一次连接的细节摆在桌上,让使用它的人感到踏实。

它适合谁?

适合那些把网络当作工具,而非玩具的人。写作者、研究者、跨境团队,以及所有在意连接是否稳定、按月付出是否值得的人,都可以在这里找到合适的位置。

它不适合谁?

如果你追求的是「永远不断」「速度第一」这类绝对承诺,代理服务并不是合适的答案。它更像一条需要共同维护的通路,我们负责线路,用户负责使用方式。

接下来该做什么?

如果还在犹豫,从基础版开始即可。一两周的时间足够判断它是否符合你的日常节奏;若是合拍,再考虑升级也不迟。我们会在用户中心保留所有升级选项,不会主动打扰。

遇到问题怎么联系?

所有套餐都可以在用户中心提交工单;旗舰版与团队版的工单会被标记为优先处理。我们尽量在 24 小时内给出首次回复,复杂问题会顺延并同步进展。
